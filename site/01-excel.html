Глава 1. Таблицы: Excel и Google Sheets

Excel кажется несерьёзным рядом с Python, но это самый распространённый инструмент анализа в мире. Заказчик пришлёт тебе файл .xlsx, а отчёт попросит «в экселе». К тому же сводная таблица — лучший способ понять идею группировки, на которой стоят и SQL, и pandas.

Всё в этой главе работает и в бесплатных Google Sheets — на Mac это самый простой вариант: ничего не нужно устанавливать. Подойдёт и Excel для Mac: функции те же, отличается только расположение некоторых кнопок. Встроенную программу Numbers лучше не брать: интерфейс в ней устроен иначе, а работодатели её не используют. Названия функций даны на английском, в скобках — русские.

1.1. Как устроена «правильная» таблица

Аналитик работает с данными в длинном формате:

  • одна строка — одно событие или объект (заказ, клиент, визит);
  • один столбец — один признак (дата, город, сумма);
  • в ячейке — одно значение;
  • никаких объединённых ячеек, пустых строк и итогов внутри данных.

Запомни этот вид — так же выглядят таблицы в базах данных и датафреймы в pandas.

1.2. Функции, которые нужно знать

Логика

IF (ЕСЛИ) — выбор из двух вариантов:

=IF(E2 >= 10000; "Крупный"; "Обычный")

Разделитель аргументов зависит от региональных настроек: в русской локали — точка с запятой, в английской — запятая.

Поиск

VLOOKUP (ВПР) подтягивает значение из другой таблицы по ключу. Это тот же JOIN из SQL, только вручную.

=VLOOKUP(A2; Клиенты!A:C; 3; FALSE)

Читается так: найди значение из A2 в первом столбце диапазона Клиенты!A:C и верни значение из третьего столбца. FALSE (ЛОЖЬ) означает точное совпадение — всегда указывай его, иначе получишь тихую ошибку.

HLOOKUP (ГПР) — то же самое, но поиск идёт по строке. В новых версиях обе функции заменяет XLOOKUP (ПРОСМОТРX).

Текст

ФункцияЧто делает

UPPER / LOWER / PROPER (ПРОПИСН / СТРОЧН / ПРОПНАЧ)Меняет регистр

TRIM и LOWER — первые помощники при очистке: «Москва », «москва» и «Москва» для компьютера — три разных города.

Даты

DATEDIF (РАЗНДАТ) считает разницу между датами:

=DATEDIF(A2; B2; "D")

Третий аргумент: "D" — дни, "M" — месяцы, "Y" — годы.

1.3. Сводные таблицы

Сводная таблица (Pivot Table) отвечает на вопрос вида «посчитай что-то в разрезе чего-то»: выручку по городам, число заказов по месяцам, средний чек по категориям.

Как построить:

  1. Выдели данные вместе с заголовками.
  2. Вставка → Сводная таблица.
  3. Перетащи поля в четыре области:
    • Строки — по чему группируем (город);
    • Столбцы — второй разрез (категория);
    • Значения — что считаем (сумма по amount);
    • Фильтры — что отсекаем (только март).

1.4. Графики

Четыре графика закрывают большую часть задач:

  • Линейный — как показатель меняется во времени.
  • Столбчатый — сравнение категорий.
  • Гистограмма — как распределены значения.
  • Точечный — связь двух числовых показателей.

Круговую диаграмму используй, только если долей не больше четырёх. Подробно о выборе графика — в главе 7.

1.5. Где Excel заканчивается

Переходи на SQL и Python, когда:

  • строк больше нескольких сотен тысяч (предел листа — 1 048 576 строк, тормозить начнёт раньше);
  • один и тот же отчёт нужно делать каждую неделю;
  • нужно объединить много файлов;
  • нужны статистические тесты.

Главный недостаток Excel — невоспроизводимость: по готовому файлу не видно, какие действия и в каком порядке с ним сделали. Код это видно всегда.

Практика на GitHub

  • В awesome-public-datasets выбери любой небольшой датасет в формате CSV и открой его в Excel или Google Sheets.
  • В noztas/DataAnalystProjects посмотри проект с дашбордом в Excel: как из сводных таблиц и срезов собирается одна страница с ответами.

Задания

  1. Создай таблицу из 30 заказов по образцу из раздела 1.1 (или возьми датасет из каталога).
  2. Посчитай выручку по Москве через SUMIFS.
  3. Добавь столбец «Размер заказа» через IF.
  4. Сделай второй лист «Города» с населением и подтяни население через VLOOKUP.
  5. Построй сводную таблицу: города в строках, категории в столбцах, сумма в значениях.
  6. Построй столбчатый график выручки по городам.

Проверь себя

  • Что такое длинный формат данных?
  • Зачем в VLOOKUP последний аргумент FALSE?
  • Какой области сводной таблицы соответствует GROUP BY?

Решения

Формулы даны для английской локали с запятой-разделителем. В русской локали замени запятые между аргументами на точку с запятой. Предполагается, что данные лежат в столбцах: A — order_id, B — date, C — city, D — category, E — amount, заголовки — в первой строке.

Задание 2. Выручка по Москве
=SUMIFS(E:E, C:C, "Москва")

Первый аргумент — что суммируем, дальше идут пары «диапазон условия, условие». Чтобы не вписывать город в формулу, вынеси его в ячейку, например H1, и сошлись на неё: =SUMIFS(E:E, C:C, H1). Тогда город меняется без правки формулы.

Проверка: сумма по всем городам должна совпасть с =SUM(E:E). Если не совпала — в названиях городов есть лишние пробелы или разный регистр.

Задание 3. Размер заказа

В ячейку F2, затем протянуть вниз:

=IF(E2>=10000, "Крупный", "Обычный")

Три градации получаются вложением:

=IF(E2>=10000, "Крупный", IF(E2>=3000, "Средний", "Мелкий"))

Условия проверяются по порядку, поэтому во втором IF уже не нужно писать «меньше 10000».

Задание 4. Население через VLOOKUP

На листе «Города» в столбце A — город, в столбце B — население. В ячейку G2 основного листа:

=VLOOKUP(C2, Города!A:B, 2, FALSE)

Если появилась ошибка #N/A (#Н/Д), значит, город не найден. Причины почти всегда две: лишние пробелы или разное написание. Лечится очисткой ключа:

=VLOOKUP(TRIM(C2), Города!A:B, 2, FALSE)

Чтобы вместо ошибки выводился текст:

=IFERROR(VLOOKUP(C2, Города!A:B, 2, FALSE), "нет в справочнике")
Задание 5. Сводная таблица
  1. Щёлкни в любую ячейку данных.
  2. Вставка → Сводная таблица → На новый лист.
  3. Поле city перетащи в «Строки», category — в «Столбцы», amount — в «Значения».
  4. Убедись, что в «Значениях» написано «Сумма по полю amount». Если там «Количество», значит, в столбце есть текст или пустые ячейки: щёлкни по полю → Параметры поля значений → Сумма.

Общий итог сводной должен совпасть с =SUM(E:E). Это стандартная проверка, которую стоит делать всегда.

Задание 6. График
  1. Построй сводную: city в строках, сумма amount в значениях.
  2. Отсортируй по убыванию: правый клик по числу → Сортировка → По убыванию.
  3. Выдели сводную → Вставка → Гистограмма (столбчатая).
  4. Дай графику заголовок-вывод («Москва приносит половину выручки») и убери легенду из одного пункта.

Сортировка обязательна: по отсортированным столбцам лидер и отстающий видны сразу.
