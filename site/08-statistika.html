Глава 8. Описательная статистика и EDA

Описательная статистика сжимает тысячи значений до нескольких чисел, по которым можно понять, как устроены данные. EDA (Exploratory Data Analysis, разведочный анализ) — это процесс знакомства с датасетом с помощью этих чисел и графиков.

На карте roadmap.sh раздел называется Descriptive Analysis и делится на три части: центральная тенденция, разброс и форма распределения.

8.1. Центральная тенденция: где «центр» данных

python
import numpy as np
import pandas as pd
from scipy import stats

salaries = pd.Series([60, 65, 70, 70, 75, 80, 85, 90, 400])   # тыс. руб.

print(salaries.mean())      # 110.56 — среднее
print(salaries.median())    # 75.0  — медиана
print(salaries.mode()[0])   # 70    — мода
Результат
110.55555555555556
75.0
70
  • Среднее (mean) — сумма, делённая на количество. Чувствительно к выбросам.
  • Медиана (median) — значение посередине отсортированного ряда: половина данных меньше, половина больше. К выбросам устойчива.
  • Мода (mode) — самое частое значение. Единственная мера, которая работает для категорий.

В примере один директор с зарплатой 400 поднял среднее до 110, хотя восемь человек из девяти получают меньше 100. «Средняя зарплата» здесь никого не описывает, медиана 75 — описывает.

Практическое правило: для денег, времени и любых величин с длинным хвостом смотри на медиану. А лучше — на оба числа: если среднее заметно больше медианы, в данных есть крупные значения справа.

8.2. Разброс: насколько данные разные

Два набора могут иметь одинаковое среднее и быть совершенно разными: [49, 50, 51] и [0, 50, 100].

python
x = pd.Series([12, 15, 11, 19, 14, 22, 13, 16])

print(x.max() - x.min())       # размах (range)
print(x.var())                 # дисперсия (variance)
print(x.std())                 # стандартное отклонение (standard deviation)
print(x.quantile([0.25, 0.5, 0.75]))          # квартили
print(x.quantile(0.75) - x.quantile(0.25))    # межквартильный размах (IQR)
Результат
11

3.693623849670827
0.25    12.75
0.50    14.50
0.75    16.75
dtype: float64

  • Размах — максимум минус минимум. Зависит от двух крайних точек, поэтому ненадёжен.
  • Дисперсия — средний квадрат отклонения от среднего. Измеряется в «квадратных» единицах, поэтому сама по себе неудобна.
  • Стандартное отклонение — корень из дисперсии. Измеряется в тех же единицах, что и данные: «типичное отклонение от среднего».
  • Перцентиль (квантиль) — значение, ниже которого лежит заданная доля данных. 90-й перцентиль времени доставки 3 дня означает: 90 % заказов доставлены не дольше чем за 3 дня.
  • IQR — расстояние между 25-м и 75-м перцентилями: ширина средней половины данных. Устойчив к выбросам.

Коэффициент вариации — стандартное отклонение, делённое на среднее. Позволяет сравнивать разброс у величин в разных единицах:

python
print(x.std() / x.mean())
Результат
0.2422048426013657

8.3. Форма распределения

Распределение — это ответ на вопрос «какие значения встречаются и как часто». Его лучший портрет — гистограмма.

python
rng = np.random.default_rng(1)
symmetric = pd.Series(rng.normal(100, 15, 5000))
skewed = pd.Series(rng.gamma(2.0, 1500, 5000))

for name, s in [("симметричное", symmetric), ("скошенное", skewed)]:
    print(name,
          "| среднее:", round(s.mean(), 1),
          "| медиана:", round(s.median(), 1),
          "| асимметрия:", round(s.skew(), 2),
          "| эксцесс:", round(s.kurt(), 2))
Результат
симметричное | среднее: 99.8 | медиана: 99.6 | асимметрия: 0.06 | эксцесс: 0.09
скошенное | среднее: 2974.0 | медиана: 2503.2 | асимметрия: 1.44 | эксцесс: 3.17
  • Асимметрия (skewness) — насколько распределение скошено. Около 0 — симметричное. Больше 0 — длинный хвост справа (доходы, суммы заказов, время на сайте). Меньше 0 — хвост слева.
  • Эксцесс (kurtosis) — насколько тяжёлые хвосты, то есть как часто встречаются экстремальные значения. У нормального распределения он равен 0 (в том определении, которое использует pandas).

Нормальное распределение

Симметричный «колокол», который задаётся средним и стандартным отклонением. Для него работает правило трёх сигм:

  • в пределах ±1 стандартного отклонения от среднего — около 68 % значений;
  • в пределах ±2 — около 95 %;
  • в пределах ±3 — около 99,7 %.
python
within_2 = ((symmetric > 100 - 30) & (symmetric < 100 + 30)).mean()
print(round(within_2, 3))    # около 0.95
Результат
0.956

Важно: большинство бизнес-данных не нормальны. Суммы заказов, число покупок, длительность сессий скошены вправо. Правило трёх сигм к ним неприменимо.

Логарифм для скошенных данных

Логарифмирование сжимает длинный хвост и часто делает распределение почти симметричным:

python
print(round(skewed.skew(), 2), round(np.log(skewed).skew(), 2))
Результат
1.44 -0.87

8.5. Связь между показателями

Корреляция

Коэффициент корреляции показывает, насколько согласованно меняются две величины. Он лежит от −1 до +1:

  • близко к +1 — растёт одна, растёт и другая;
  • близко к −1 — одна растёт, другая падает;
  • около 0 — линейной связи нет.
python
users = (
    df.groupby("user_id")
      .agg(orders=("order_id", "count"), revenue=("amount", "sum"), avg_check=("amount", "mean"))
)

print(users.corr())                       # корреляция Пирсона
print(users.corr(method="spearman"))      # корреляция Спирмена

r, p_value = stats.pearsonr(users["orders"], users["revenue"])
print(round(r, 3), p_value)
Результат

  • Пирсон измеряет линейную связь и чувствителен к выбросам.
  • Спирмен работает с рангами: ловит любую монотонную связь и устойчив к выбросам. Для скошенных данных он надёжнее.

Три ловушки корреляции

  1. Корреляция не означает причинность. Продажи мороженого и число утонувших растут вместе — потому что и то и другое зависит от жары. Третью величину, которая влияет на обе, называют конфаундером.
  2. Нулевая корреляция не означает отсутствия связи. Она измеряет только линейную связь: зависимость в форме параболы даст коэффициент около нуля.
  3. Один выброс может создать или уничтожить корреляцию. Поэтому сначала всегда точечный график, потом число.

Простая линейная регрессия

Регрессия идёт дальше корреляции: она не только говорит, что связь есть, но и описывает её уравнением y = a + b·x.

python
result = stats.linregress(users["orders"], users["revenue"])

print("наклон:", round(result.slope, 1))
print("свободный член:", round(result.intercept, 1))
print("R²:", round(result.rvalue ** 2, 3))
Результат
наклон: 3065.8
свободный член: -355.4
R²: 0.684
  • Наклон — на сколько в среднем меняется y при росте x на единицу. Здесь: сколько выручки приносит каждый дополнительный заказ.
  • R² — доля разброса y, которую объясняет модель: от 0 до 1.

8.6. Парадокс Симпсона

Тенденция, которая видна в каждой группе по отдельности, может исчезнуть или перевернуться при объединении групп.

python
data = pd.DataFrame({
    "variant":   ["A", "A", "B", "B"],
    "platform":  ["mobile", "desktop", "mobile", "desktop"],
    "visitors":  [8000, 2000, 2000, 8000],
    "purchases": [240, 200, 50, 720],
})
data["cr"] = data["purchases"] / data["visitors"]
print(data)

total = data.groupby("variant")[["visitors", "purchases"]].sum()
total["cr"] = total["purchases"] / total["visitors"]
print(total)

8.7. План разведочного анализа

Схема, по которой можно пройти любой датасет. Она же — готовая структура проекта для портфолио.

  1. Контекст. Откуда данные, что означает одна строка, за какой период.
  2. Структура. shape, info(), head(): размеры, типы.
  3. Качество. Пропуски, дубликаты, ошибки (чек-лист из главы 6).
  4. Каждый столбец по отдельности.
    • числовой — describe(), гистограмма, boxplot;
    • категориальный — value_counts(), столбчатый график;
    • дата — число записей по дням: нет ли дыр и всплесков.
  5. Пары столбцов.
    • число × число — точечный график, корреляция;
    • число × категория — boxplot, groupby().agg();
    • категория × категория — crosstab, тепловая карта.
  6. Время. Тренд, сезонность, день недели.
  7. Сегменты. Повтори ключевые расчёты в разрезах.
  8. Выводы. 3–5 находок, каждая: что увидел → что это значит → что делать.

Последний пункт важнее всех предыдущих. EDA без выводов — это просто набор картинок.

Задание 2. Правило трёх сигм
python
import numpy as np

rng = np.random.default_rng(0)
x = rng.normal(loc=100, scale=15, size=10_000)

mean, std = x.mean(), x.std()
for k in (1, 2, 3):
    share = ((x > mean - k * std) & (x < mean + k * std)).mean()
    print(f"в пределах ±{k} сигм: {share:.1%}")
Результат
в пределах ±1 сигм: 68.2%
в пределах ±2 сигм: 95.4%
в пределах ±3 сигм: 99.8%

Получится около 68 %, 95 % и 99,7 %. Повтори то же для скошенных данных (rng.gamma(2.0, 1500, 10_000)) и убедись, что доли другие: правило работает только для нормального распределения.

Задание 4. Корреляция для параболы
python
import numpy as np

x = np.linspace(-3, 3, 100)
y = x ** 2

print(round(np.corrcoef(x, y)[0, 1], 6))      # практически 0
Результат
0.0

Связь между x и y полная — y однозначно вычисляется из x. Но корреляция Пирсона равна нулю, потому что она измеряет только линейную связь: на левой половине y убывает с ростом x, на правой — возрастает, и два эффекта взаимно уничтожаются.

Если взять только правую половину, корреляция станет высокой:

python
mask = x > 0
print(round(np.corrcoef(x[mask], y[mask])[0, 1], 3))     # около 0.97
Результат
0.968

Вывод: нулевая корреляция не означает отсутствия связи. Сначала точечный график — потом коэффициент.

Задание 5. EDA-проект

Это задание без единственного верного ответа. Ниже — каркас ноутбука, который нужно наполнить.

python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

DATA_PATH = "data/dataset.csv"


def overview(df: pd.DataFrame) -> pd.DataFrame:
    """Сводка по каждому столбцу: тип, пропуски, число уникальных значений, пример."""
    return pd.DataFrame({
        "тип": df.dtypes.astype(str),
        "пропусков": df.isna().sum(),
        "доля пропусков": df.isna().mean().round(3),
        "уникальных": df.nunique(),
        "пример": df.iloc[0],
    })


def plot_numeric(df: pd.DataFrame, column: str) -> None:
    """Гистограмма и ящик с усами для числового столбца."""
    fig, axes = plt.subplots(1, 2, figsize=(11, 3.5))
    sns.histplot(df[column].dropna(), bins=40, ax=axes[0])
    sns.boxplot(x=df[column], ax=axes[1])
    fig.suptitle(column)
    fig.tight_layout()
    plt.show()


def plot_category(df: pd.DataFrame, column: str, top: int = 10) -> None:
    """Столбчатый график самых частых значений категориального столбца."""
    counts = df[column].value_counts().head(top).sort_values()
    counts.plot(kind="barh", figsize=(7, 3.5), title=column)
    plt.show()
