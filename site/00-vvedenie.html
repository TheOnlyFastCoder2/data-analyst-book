Глава 0. Профессия и подготовка

0.1. Чем занимается аналитик данных

Аналитик отвечает на вопросы бизнеса с помощью данных. Не «строит графики» и не «пишет код» — это только инструменты. Результат его работы — решение, которое приняли на основе его выводов.

Типичные вопросы, с которыми приходят к аналитику:

  • Почему в марте упали продажи?
  • Какой из двух вариантов кнопки приносит больше заказов?
  • Сколько клиентов уйдёт от нас в следующем месяце?
  • На какой рекламный канал тратить бюджет?

Типичный рабочий цикл выглядит так:

  1. Понять вопрос. Что именно хотят узнать и какое решение от этого зависит.
  2. Собрать данные. Обычно SQL-запросом из базы компании.
  3. Очистить. Убрать дубликаты, разобраться с пропусками и ошибками.
  4. Исследовать. Посчитать метрики, построить графики, найти закономерности.
  5. Проверить. Убедиться, что находка — не случайность (статистика).
  6. Рассказать. Написать вывод понятным языком и дать рекомендацию.

Шаги 2–5 — это техника, ей и посвящена книга. Но шаги 1 и 6 отличают сильного аналитика от слабого, поэтому к ним мы будем возвращаться в каждой главе.

0.2. Четыре типа аналитики

ТипВопросПримерИнструменты
Описательная (descriptive)Что произошло?Выручка в марте упала на 12 %SQL, pandas, дашборды
Диагностическая (diagnostic)Почему это произошло?Упала конверсия у пользователей Android после обновленияСегментация, воронки, гипотезы
Предсказательная (predictive)Что произойдёт?В апреле уйдёт около 800 клиентовРегрессия, ML-модели
Предписывающая (prescriptive)Что делать?Дать скидку 10 % клиентам из группы рискаЭксперименты, оптимизация

Начинающий аналитик 90 % времени работает с первыми двумя типами. Поэтому главы 1–10 — про них, а глава 11 даёт обзор остальных.

0.3. Ключевые этапы работы с данными

На карте roadmap.sh они названы Key Concepts of Data. В скобках — глава, где это разбирается.

  • Collection — сбор: базы данных, файлы, API, парсинг сайтов (главы 3, 3А и 6).
  • Cleanup — очистка (глава 6).
  • Exploration — исследование (главы 5, 5А и 8).
  • Visualisation — визуализация и BI (главы 7 и 7А).
  • Statistical Analysis — статистика и A/B-тесты (главы 8, 9 и 9А).
  • Machine Learning — машинное обучение (глава 11).

0.4. Что нужно знать, чтобы взяли на работу

Если отсортировать навыки по тому, как часто их спрашивают на собеседованиях на позицию junior:

  1. SQL — спрашивают всегда (главы 3 и 3А).
  2. Python + pandas — почти всегда (главы 2–2В, 5 и 5А).
  3. Статистика и A/B-тесты — почти всегда, особенно в продуктовых компаниях (главы 8, 9 и 9А).
  4. Продуктовые метрики — в продуктовых компаниях.
  5. Визуализация и BI (Power BI, Tableau, DataLens) — часто (главы 7 и 7А).
  6. Excel — в небольших и нетехнологических компаниях.
  7. Машинное обучение — редко и только на базовом уровне.

Вывод: не начинай с нейросетей. Начни с Python, SQL и pandas.

0.5. Настройка компьютера

Здесь — короткая версия. Подробный разбор каждой команды, виртуальных окружений, структуры проекта и типичных ошибок вынесен в отдельную главу: Установка и настройка: полное руководство.

Все команды в книге даны для macOS.

Терминал и Python

  1. Открой Терминал: Cmd+Пробел, набери Terminal, нажми Enter.
  2. Установи инструменты разработчика Apple (в них входит Git):
bash
xcode-select --install
  1. Установи Python: скачай установщик для macOS с python.org (версия 3.11 или новее) либо, если у тебя есть Homebrew, выполни brew install python.
  2. Проверь:
bash
python3 --version

Должно появиться что-то вроде Python 3.12.x. На macOS команда называется python3; просто python заработает после активации окружения.

Рабочая папка и библиотеки

Создай папку для учёбы и виртуальное окружение в ней. Окружение — это изолированный набор библиотек для одного проекта.

bash
mkdir -p ~/projects/analyst
cd ~/projects/analyst
python3 -m venv .venv

Активируй окружение — это нужно делать в каждом новом окне терминала:

bash
source .venv/bin/activate

В начале строки появится (.venv). Установи библиотеки, которые понадобятся в книге:

bash
pip install numpy pandas matplotlib seaborn scipy statsmodels scikit-learn requests beautifulsoup4 jupyterlab

Jupyter

Jupyter — это «тетрадка», где код выполняется по кусочкам (ячейкам), а результат виден сразу под ячейкой. Аналитики работают в основном в нём.

bash
jupyter lab

Откроется вкладка в браузере. Создай новый ноутбук, набери в ячейке 2 + 2 и нажми Shift+Enter.

Самые нужные клавиши:

КлавишиДействие
Shift+EnterВыполнить ячейку и перейти к следующей
Esc, затем A / BДобавить ячейку выше / ниже
Esc, затем D DУдалить ячейку
Esc, затем MПревратить ячейку в текст (Markdown)

Альтернатива без установки — Google Colab: те же ноутбуки, но в браузере.

Git и GitHub

Git хранит историю изменений, GitHub — показывает твою работу миру. Для аналитика GitHub — это портфолио.

  1. Зарегистрируйся на github.com.
  2. Git уже установлен вместе с инструментами разработчика. Представься ему (git config --global user.name ...) и войди в GitHub — как именно, описано в руководстве.
  3. Создай на GitHub пустой репозиторий, например analyst-learning.
  4. Свяжи с ним свою папку:
bash
git init
git add .
git commit -m "Первый ноутбук"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/analyst-learning.git
git push -u origin main

Дальше после каждого занятия повторяй три команды: git add ., git commit -m "что сделал", git push.

Чтобы скачать чужой репозиторий для практики:

bash
git clone https://github.com/guipsamora/pandas_exercises.git

0.6. Как пользоваться репозиториями-каталогами

Три ссылки держи в закладках, но не пытайся пройти их целиком — это справочники, а не курсы:

  • developer-roadmap — карта: что и в каком порядке учить. Сверяйся с ней раз в месяц и отмечай пройденное.
  • PavelGrigoryevDS/awesome-data-analysis — каталог из 500+ ресурсов по разделам. Открывай, когда тема из книги не зашла и нужно другое объяснение.
  • academic/awesome-datascience — ещё один большой каталог, с уклоном в Data Science.

Главная ловушка новичка — собирать ссылки вместо того, чтобы учиться. Правило: новый ресурс открываешь только тогда, когда закончил текущий.

Задания

  1. Установи Python, создай окружение, запусти Jupyter.
  2. Создай репозиторий на GitHub и запушь в него первый ноутбук с ячейкой print("Привет, аналитика!").
  3. Открой карту Data Analyst на roadmap.sh и найди на ней пять терминов, которые тебе незнакомы. Запиши их — в конце книги проверишь, что все стали понятны.
