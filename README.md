# Аналитик данных: от нуля до первой работы

Практический учебник по Python, SQL и анализу данных. Вся практика — на открытых репозиториях GitHub.

## Для кого эта книга

Для человека, который никогда не программировал, но хочет стать аналитиком данных. Нужны только школьная математика, компьютер и 8–10 часов в неделю.

## Как устроена книга

Порядок глав повторяет карту **Data Analyst** с [roadmap.sh](https://roadmap.sh/data-analyst) (репозиторий [developer-roadmap](https://github.com/kamranahmedse/developer-roadmap)). Каждая глава состоит из пяти частей:

1. **Теория** — коротко и на примерах, которые можно запустить.
2. **Практика на GitHub** — какой репозиторий открыть и что именно в нём сделать.
3. **Задания** — что нужно сделать самому.
4. **Проверь себя** — вопросы, на которые ты должен отвечать без подсказок.
5. **Решения** — разбор каждого задания с объяснением. Открывай только после собственной попытки.

Книга не заменяет репозитории, а ведёт по ним: объясняет идею, а отрабатывать её отправляет к первоисточнику.

## План на 9 месяцев

При темпе 8–10 часов в неделю.

| Недели | Главы | Контрольная точка |
|--------|-------|-------------------|
| 1 | 0, 1 | Установлен Python, создан репозиторий, сделана сводная таблица |
| 2–4 | 2 | Решено 30+ простых задач на Python |
| 5–8 | 2А, 2Б, 2В | Написаны свой декоратор, свой класс и конвейер обработки; код отформатирован ruff |
| 9–12 | 3 | Решено 50+ SQL-задач, из них 10 с оконными функциями |
| 13–14 | 3А | Написаны запросы на сессии, серии и когорты; каждый запрос проверен |
| 15 | 4 | Пройдена первая треть numpy-100 |
| 16–19 | 5, 6 | Пройдены разделы 1–6 pandas_exercises, очищен один «грязный» датасет |
| 20–21 | 5А | Решены задачи главы без `apply` по строкам; заведён свой модуль с рецептами |
| 22–23 | 7 | 8 типов графиков построены на своих данных |
| 24–25 | 7А | Свой стиль графиков; опубликован дашборд в DataLens или Tableau Public |
| 26–28 | 8, 9 | Сделан полный EDA и один разобранный A/B-тест |
| 29–30 | 9А | Проведены симуляции мощности и A/A; написан отчёт по тесту |
| 31–32 | 10 | Посчитаны воронка и когортный retention |
| 33 | 11 | Обучена и оценена одна модель |
| 34–38 | 12, 13 | 3–4 проекта на GitHub, готово резюме |

Главы с буквой «А» — углублённые. Если нужно быстрее выйти на собеседования, при первом проходе их можно пропустить и вернуться позже: без них план занимает около семи месяцев. Но именно они дают то, что спрашивают после вопросов «на знание синтаксиса».

Не укладываешься — не страшно. Важна не скорость, а регулярность: час каждый день лучше, чем семь часов в воскресенье.

## Три правила, без которых ничего не получится

1. **Печатай код руками.** Не копируй. Ошибки при наборе — это и есть обучение.
2. **Сначала попробуй сам, потом смотри решение.** Минимум 15 минут честных попыток.
3. **Всё, что сделал, клади на GitHub.** Через полгода это станет твоим портфолио.
