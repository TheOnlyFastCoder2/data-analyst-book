# Глава 4. NumPy

NumPy — библиотека для быстрых вычислений с массивами чисел. Напрямую аналитик пользуется ею не каждый день, но на ней построены pandas, SciPy и scikit-learn. Понимание NumPy объясняет, почему pandas ведёт себя именно так.

Глава короткая: нужны три идеи — массив, векторные операции и оси.

## 4.1. Массив вместо списка

```python
import numpy as np

prices = [100, 250, 80, 410]

# Список: нужен цикл
with_tax = [p * 1.2 for p in prices]

# Массив: операция применяется ко всем элементам сразу
arr = np.array(prices)
print(arr * 1.2)        # [120. 300.  96. 492.]
print(arr.dtype)        # целочисленный тип, например int64
print(arr.shape)        # (4,)
```

Отличия массива от списка:

- все элементы одного типа;
- арифметика работает поэлементно, без циклов — это называют **векторизацией**;
- на больших данных вычисления быстрее в десятки и сотни раз.

Главное правило, которое перейдёт и в pandas: **если пишешь цикл по строкам данных — скорее всего, есть способ без цикла**.

## 4.2. Создание массивов

```python
print(np.zeros(3))               # [0. 0. 0.]
print(np.ones((2, 3)))           # матрица 2×3 из единиц
print(np.arange(0, 10, 2))       # [0 2 4 6 8]
print(np.linspace(0, 1, 5))      # [0.   0.25 0.5  0.75 1.  ]

rng = np.random.default_rng(seed=42)       # генератор случайных чисел
print(rng.integers(1, 7, size=5))          # 5 бросков кубика
print(rng.normal(loc=100, scale=15, size=3))  # нормальное распределение
```

`seed` фиксирует случайность: с одним и тем же зерном результат всегда одинаковый. В аналитике это обязательно — иначе твой расчёт никто не сможет повторить.

## 4.3. Индексация и фильтрация

```python
a = np.array([15, 42, 8, 23, 4, 16])

print(a[0])       # 15
print(a[-1])      # 16
print(a[1:4])     # [42  8 23]
```

Булева маска — самый важный приём главы. Сравнение массива с числом даёт массив из `True` и `False`, и по нему можно отобрать элементы:

```python
mask = a > 15
print(mask)          # [False  True False  True False  True]
print(a[mask])       # [42 23 16]
print(a[(a > 10) & (a < 30)])   # [15 23 16]
print(mask.sum())    # 3 — сколько элементов прошло условие
print(mask.mean())   # 0.5 — их доля
```

Обрати внимание:

- условия объединяются через `&` (и), `|` (или), `~` (не), а не через `and` / `or`;
- каждое условие берётся в скобки;
- `True` считается как 1, поэтому `mask.mean()` — готовая доля. Так считают конверсию.

`np.where` — векторный аналог `if / else`:

```python
print(np.where(a > 15, "много", "мало"))
```

## 4.4. Двумерные массивы и оси

```python
# Продажи: 3 магазина (строки) × 4 квартала (столбцы)
sales = np.array([
    [10, 12, 15, 20],
    [ 8,  9, 11, 14],
    [20, 18, 25, 30],
])

print(sales.shape)        # (3, 4)
print(sales[0, 1])        # 12 — первая строка, второй столбец
print(sales[:, 0])        # [10  8 20] — весь первый столбец
print(sales[1, :])        # [ 8  9 11 14] — вся вторая строка

print(sales.sum())            # 192 — по всем элементам
print(sales.sum(axis=0))      # [38 39 51 64] — итог по каждому кварталу
print(sales.sum(axis=1))      # [57 42 93] — итог по каждому магазину
```

Как запомнить оси: `axis=0` — идём **вниз по строкам** и получаем результат для каждого столбца; `axis=1` — идём **вправо по столбцам** и получаем результат для каждой строки. В pandas оси работают так же.

## 4.5. Статистика

```python
x = np.array([12, 15, 11, 19, 14, 95])

print(x.mean())               # 27.666... — среднее
print(np.median(x))           # 14.5 — медиана
print(x.std(ddof=1))          # стандартное отклонение по выборке
print(np.percentile(x, 90))   # 90-й перцентиль
print(x.min(), x.max(), x.argmax())   # 11 95 5
```

Заметь: одно значение 95 утянуло среднее до 27,7, а медиана осталась 14,5. К этому вернёмся в главе 8.

Параметр `ddof=1` включает деление на `n − 1` — так считают отклонение по выборке. В NumPy по умолчанию `ddof=0`, в pandas — `ddof=1`. Из-за этого два инструмента могут дать немного разные числа, и это не ошибка.

## 4.6. Broadcasting

Broadcasting — правило, по которому NumPy выполняет операции над массивами разной формы, «растягивая» меньший.

```python
sales = np.array([
    [10, 12, 15, 20],
    [ 8,  9, 11, 14],
    [20, 18, 25, 30],
])

# Доля каждого магазина в продажах квартала
quarter_total = sales.sum(axis=0)          # форма (4,)
share = sales / quarter_total              # (3, 4) / (4,) — делится каждая строка
print(share.round(2))

# Доля каждого квартала в продажах магазина
store_total = sales.sum(axis=1, keepdims=True)   # форма (3, 1)
print((sales / store_total).round(2))
```

`keepdims=True` сохраняет результат в виде столбца, чтобы формы совпали.

## 4.7. Пропуски: NaN

`np.nan` — «не число», так обозначают пропущенные значения.

```python
v = np.array([10.0, np.nan, 30.0])

print(v.mean())          # nan — пропуск «заражает» результат
print(np.nanmean(v))     # 20.0 — версия функции, игнорирующая пропуски
print(np.isnan(v))       # [False  True False]
print(np.nan == np.nan)  # False — NaN не равен даже самому себе
```

Последняя строка — причина, по которой пропуски ищут специальными функциями, а не сравнением.

## Задания

1. Создай массив из 1000 случайных чисел из нормального распределения со средним 50 и отклонением 10. Какая доля значений больше 60?
2. Без циклов замени в массиве все отрицательные числа на 0.
3. Смоделируй 10 000 бросков двух кубиков. Как часто выпадает сумма 7? Сравни с теоретической вероятностью 1/6.
4. Для матрицы `sales` из раздела 4.4 найди магазин с максимальными продажами за год и лучший квартал каждого магазина.
5. Нормализуй массив: вычти среднее и раздели на стандартное отклонение. Проверь, что новое среднее равно 0.

## Проверь себя

- Что вернёт `(a > 10).mean()`?

## Решения

### Задание 1. Доля значений больше 60

```python
import numpy as np

rng = np.random.default_rng(42)
values = rng.normal(loc=50, scale=10, size=1000)

print((values > 60).mean())       # около 0.16
```

Сравнение даёт массив из `True` и `False`, а `mean` считает долю `True`. Теоретически ответ — около 15,9 %: значение 60 лежит на одно стандартное отклонение выше среднего, а за пределами ±1 отклонения находится около 32 % значений, половина из них — справа.

### Задание 2. Отрицательные заменить на 0

```python
a = np.array([3, -1, 4, -5, 9])

print(np.where(a < 0, 0, a))      # [3 0 4 0 9]
print(np.clip(a, 0, None))        # то же: обрезать снизу нулём
print(np.maximum(a, 0))           # то же: поэлементный максимум с нулём
```

Все три способа возвращают новый массив. Изменить на месте можно так: `a[a < 0] = 0`.

### Задание 3. Два кубика

```python
rng = np.random.default_rng(1)
dice = rng.integers(1, 7, size=(10_000, 2))     # 10 000 бросков по два кубика
sums = dice.sum(axis=1)                         # сумма в каждой строке

print((sums == 7).mean(), 1 / 6)                # около 0.167 и 0.1667
```

Верхняя граница в `integers(1, 7)` не включается, поэтому значения — от 1 до 6. Сумму 7 дают 6 комбинаций из 36, отсюда 1/6. Результат симуляции немного отличается от теории — это нормальная случайная погрешность, она уменьшается с ростом числа бросков.

### Задание 4. Лучший магазин и лучший квартал

```python
sales = np.array([
    [10, 12, 15, 20],
    [ 8,  9, 11, 14],
    [20, 18, 25, 30],
])

by_store = sales.sum(axis=1)
print(by_store, "лучший магазин:", by_store.argmax())             # [57 42 93] лучший магазин: 2
print("лучший квартал каждого магазина:", sales.argmax(axis=1))   # [3 3 3]
```

`argmax` возвращает не значение, а **позицию** максимума. Нумерация с нуля: магазин 2 — третий по счёту, квартал 3 — четвёртый.

### Задание 5. Нормализация

```python
x = np.array([12, 15, 11, 19, 14, 22], dtype=float)

z = (x - x.mean()) / x.std()
print(z.round(2))
print(round(z.mean(), 10), round(z.std(), 10))    # 0.0 1.0
```

Такое преобразование называют стандартизацией или z-оценкой. Значение `z` показывает, на сколько стандартных отклонений элемент отстоит от среднего. Среднее получается не ровно ноль, а что-то вроде `1e-17` — это погрешность вычислений с дробными числами, поэтому мы округляем.
